# StreakBoard 

A lightweight, private, offline-first habit tracker, week planner, and goal management dashboard.

## Features
- **100% Offline & Private**: Zero external network calls, no cloud tracking, no logins required. All data is safely stored locally in your browser (`localStorage`).
- **Habit Tracker**: Track streaks, daily completions, schedules, and custom habit colors/icons.
- **Week & Month Planning**: Boss tasks, daily Big 3 priorities, win journals, and habit completion heatmaps.
- **Goals & Mindset Tracker**: Monitor energy, focus, and mood trends alongside quantifiable yearly goals.
- **Money & Budgeting Tab**: Track expenses, monthly budgets, and savings goals.
- **XP & Gamification**: Level up as you build consistency across habits and tasks.

## Quick Start
1. Double-click `start.bat` (on Windows), or run:
   ```bash
   node server.js
   ```
2. Open [http://localhost:3000](http://localhost:3000) in your web browser.
3. Alternatively, you can open `index.html` directly in any web browser without running a server.
